# 독립 리뷰 브리프

## 목표

이 저장소가 한 고급 LLM 에이전트 사용자의 작업 방식을 다른 사람에게 설명하고, 독자가 자신의 프로젝트에 최소 형태부터 적용할 수 있게 한다.

## 필수 내용

- 초급, 중급, 고급 사용 방식
- 공통 운영 파일과 범용 rule 예시
- 자주 사용하는 워크플로우 패턴
- 다양한 하네스 형태와 선택 기준
- 실제로 자주 사용하는 오픈소스 skill/plugin 범주
- 핵심 개념과 독립 검증 방식
- 복사 가능한 작업 계약

## 경계

- 개인 프로젝트, 사용자명, 로컬 경로, credential을 노출하지 않는다.
- 특정 모델이나 도구를 유일한 정답처럼 마케팅하지 않는다.
- 작은 작업에 과도한 다중 에이전트 구조를 요구하지 않는다.
- 제품 설계, delivery 계획, 현재 실행 상태, 장기 memory를 구분한다.

## 리뷰 요청

`docs/review-criteria.md`의 관점으로 전체 저장소를 적대적으로 검토한다. 문서나 저장소는 수정하지 않는다. 구체적인 문제만 심각도순으로 보고하고 마지막에 `ACCEPT`, `REVISE`, `REJECT` 중 하나를 판정한다.
