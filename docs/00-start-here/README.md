# Start here

Claude Code가 익숙하지 않다면 다음 순서로 읽는다.

1. [15분 Quickstart](quickstart.md): 실제 저장소에서 첫 작업을 끝낸다.
2. [기본 정신모델](mental-model.md): 채팅과 agent의 차이를 이해한다.
3. [팀 도입 가이드](team-adoption.md): 회사 규칙과 개인 습관을 분리한다.

처음부터 plugin, MCP, subagent, worktree를 모두 설치할 필요는 없다. 첫 성공은 기존 코드를 안전하게 읽고 작은 변경을 검증하는 것이다.
