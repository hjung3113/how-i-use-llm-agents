# Start here

Claude Code가 익숙하지 않다면 저자의 [전체 사용 방식](../../README.md#한-장으로-보는-내가-실제로-쓰는-방식)과 설명을 먼저 이해하고 적용은 선택한다.

1. [기본 정신모델](mental-model.md): 채팅과 agent의 차이, context와 검증의 이유를 이해한다.
2. [쉬운 용어집](glossary.md): 반복해서 등장하는 단어와 혼동 경계를 이해한다.
3. [선택: 15분 Quickstart](quickstart.md): 이해한 방식을 실제 저장소에서 경험한다.
4. [팀 도입 가이드](team-adoption.md): 회사 규칙과 개인 습관을 분리한다.

처음부터 plugin, MCP, subagent, worktree를 모두 설치할 필요는 없다. 먼저 왜 context·scope·evidence를 구분하는지 이해하고, 적용할 준비가 되면 기존 코드를 안전하게 읽고 작은 변경을 검증한다.
