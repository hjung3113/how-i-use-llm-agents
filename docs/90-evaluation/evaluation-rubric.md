# 평가 방식과 완료 조건

이 문서는 저장소를 수정하기 전에 고정한 평가 계약이다. 목표 독자는 **회사가 Claude Code를 도입했지만 아직 agent workflow, rule file, skill, subagent, worktree에 익숙하지 않은 개발자와 기술 리더**다.

평가는 자동 검사, 독자 과제, 독립 리뷰의 세 층으로 진행한다.

## 평가 방식

### 1. 자동 검사

- 모든 내부 Markdown 링크가 실제 파일을 가리킨다.
- `git diff --check`가 통과한다.
- 개인 경로, 내부 프로젝트명, credential 패턴이 없다.
- README에서 모든 핵심 문서로 두 번 이내에 이동할 수 있다.
- 예시 파일에는 placeholder와 실제 정책이 명확히 구분되어 있다.

### 2. 독자 과제

리뷰어는 기존 프로젝트 맥락 없이 다음 과제를 수행할 수 있어야 한다.

1. 2분 안에 이 저장소의 핵심 주장을 한 문장으로 설명한다.
2. 자신의 숙련도와 작업 위험에 맞는 시작 경로를 고른다.
3. 15분 안에 최소 `AGENTS.md`와 `CLAUDE.md`를 자신의 저장소에 적용한다.
4. `CONTEXT.md`, `MEMORY.md`, `HANDOFF.md`의 차이를 설명한다.
5. 작은 수정에 단일 에이전트, 중요한 수정에 독립 리뷰를 선택한다.
6. 로컬 수정, commit, push, merge의 승인 경계를 구분한다.
7. 작업 완료 주장을 뒷받침할 최소 증거를 고른다.

### 3. 독립 리뷰

두 축을 분리해 검토한다.

- **독자/Spec:** 대상 독자가 실제로 이해하고 적용할 수 있는가? 요청한 내용이 빠짐없이 있는가?
- **구조/Standards:** 문서 책임이 겹치지 않고, 탐색 가능하며, 안전하고 유지 가능한가?

리뷰 finding은 심각도, 정확한 위치, 독자 영향, 근거, 최소 수정 방향을 포함한다.

## 점수표

각 영역을 0–5점으로 평가한 후 가중치를 적용한다.

| 영역 | 가중치 | 5점 기준 |
|---|---:|---|
| 대상 독자와 전달력 | 20 | 초보자가 용어 장벽 없이 핵심 주장과 다음 행동을 이해한다. |
| 정보 구조와 탐색성 | 20 | README, 학습 경로, reference, example의 책임이 분명하고 중복이 작다. |
| 실전 적용성 | 20 | 최소 설정, 문서 구조, 작업 계약, end-to-end 예시를 그대로 적용할 수 있다. |
| 정확성과 권위 분리 | 15 | instruction, product truth, delivery scope, live evidence, memory를 혼동하지 않는다. |
| 안전과 회사 공유 적합성 | 15 | 승인, 비밀, 기존 변경, 외부 효과, 독립 검증 경계가 명확하다. |
| 도구 중립성과 유지관리 | 10 | Claude 입문에 유용하면서 핵심 방식은 다른 agent harness에도 이동 가능하다. |

점수 의미:

- 0: 없음 또는 반대되는 내용
- 1: 이름만 언급
- 2: 설명은 있으나 적용하기 어려움
- 3: 기본 적용 가능하지만 중요한 공백이 있음
- 4: 대상 독자가 독립적으로 적용 가능
- 5: 적용·검증·실패 복구까지 일관됨

## 필수 Gate

총점과 무관하게 모두 통과해야 한다.

- [ ] 첫 화면에 대상 독자, 얻는 결과, 권장 시작 경로가 있다.
- [ ] 15분 quickstart가 실제 파일과 검증 가능한 결과로 끝난다.
- [ ] 자주 사용하는 `docs/` 구조와 각 문서의 목적·수명·권위가 예시로 제공된다.
- [ ] `AGENTS.md`, `CLAUDE.md`, `CONTEXT.md`, `MEMORY.md`, `HANDOFF.md` 예시가 있다.
- [ ] 초급 → 중급 → 고급의 상승 조건과 과설계를 피하는 하향 조건이 있다.
- [ ] 실제 세션에서 추출한 공통 패턴이 개인 정보를 제거한 형태로 설명된다.
- [ ] 테스트, review, CI, black-box evidence의 범위와 한계가 구분된다.
- [ ] local commit과 remote publication의 승인 경계가 구분된다.
- [ ] 모든 내부 링크, whitespace, privacy 자동 검사가 통과한다.
- [ ] 독립 리뷰에 High finding이 없고, 미해결 Medium finding이 없다.

## 완료 조건

다음 조건을 모두 만족하면 이번 재구조화를 완료한다.

1. 필수 gate 10개가 모두 통과한다.
2. 가중 총점이 85/100 이상이다.
3. 모든 영역이 최소 3.5/5 이상이다.
4. 독자/Spec 및 구조/Standards 독립 리뷰가 모두 `ACCEPT`다.
5. 리뷰 후 수정이 있었다면 해당 finding만 재검토해 회귀가 없음을 확인한다.
6. 결과와 평가표가 저장소에 기록되고 local `main`과 `origin/main`이 일치한다.

Low finding은 핵심 이해·적용·안전을 막지 않는 경우 다음 개선 항목으로 남길 수 있다. 점수를 올리기 위한 장식적 문서나 새로운 ceremony는 추가하지 않는다.
