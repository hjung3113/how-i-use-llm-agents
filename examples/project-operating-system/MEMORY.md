# MEMORY.md

반복 사용 가치가 있고 검증된 교훈만 기록한다. 현재 Git·PR·Issue 상태는 여기에 고정하지 않는다.

## 사용자 작업 선호

- 현재 상태를 확인한 뒤 계획한다.
- 기존 사용자 변경을 보존한다.
- 중요한 결과는 독립 검증을 거친다.
- 완료와 배포, merge와 Issue 종료를 서로 다른 상태로 취급한다.

## 기록하지 않는 것

- credential과 개인정보
- 원문 대화 전체
- 검증되지 않은 추측
- 현재 branch, HEAD, 열린 PR 등 빠르게 변하는 상태
