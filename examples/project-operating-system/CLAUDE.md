# CLAUDE.md

이 파일은 Claude Code용 얇은 어댑터다. 공통 작업 정책의 단일 원천은 `AGENTS.md`다.

## 시작 순서

1. 루트 `AGENTS.md`를 읽고 따른다.
2. `CONTEXT.md`에서 제품 목적과 권위 문서를 확인한다.
3. 현재 작업에 해당하는 하위 디렉터리 규칙을 확인한다.
4. 재개 작업이면 `HANDOFF.md`를 읽은 후 현재 Git과 런타임 상태를 다시 검증한다.

## Claude 전용 규칙

- 내장 plan, agent, skill은 작업 복잡도에 비례해 사용한다.
- 독립 리뷰를 맡은 subagent에는 수정 권한을 주지 않는다.
- 병렬 subagent가 같은 파일을 수정하지 않도록 소유 범위를 먼저 나눈다.
- 긴 조사 결과는 대화에 전부 붙이지 말고 저장소의 명시적 artifact로 남긴다.
- 공통 정책을 이 파일에 복제하지 말고 `AGENTS.md`를 수정한다.
